# Portfólio pessoal — Noé Samuel Vilanculos
Site de currículo e portfólio construído exclusivamente com HTML5 e CSS3, sem frameworks e sem JavaScript. Para visualizar, abra `index.html` num navegador.

## Páginas
- `index.html`: apresentação e chamada para os projetos.
- `about.html`: formação, experiência e tabela de competências.
- `portfolio.html`: grelha CSS Grid com projetos selecionados e espaço de demonstração em vídeo.
- `hobbies.html`: interesses organizados com Flexbox e reprodutor de áudio.
- `contact.html`: formulário com validação HTML5 nativa.
